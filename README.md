# 🎯 九州たんけんダーツ Ver.2

## 1. アプリ概要

「今日はどこに行こう？」

そんなときに、ダーツで運命の探検先を決めるWebアプリです。

九州の自然・観光地・歴史スポットなどを舞台に、行き先をランダムに決定します。

気分や同行者に合わせて候補を絞り込むこともできます。

今回のlocalStorage課題では、ダーツで見つけた観光地を保存して、後から見返せる「行きたいリスト」機能を追加しました。

**テーマ：まだ知らない九州に出会おう。**

## 3. 遊び方

1. 今日の気分を選ぶ
2. 子ども連れ・ペット連れなどの条件を選ぶ
3. 「ダーツを投げる！」ボタンを押す
4. ダーツのアニメーション後、運命の探検先が発表される
5. 写真・ミッション・同行条件を確認する
6. Googleマップで場所を確認する
7. 行きたい場所だったら「❤️ ここに行く！」ボタンで保存する
8. 「❤️ 行きたいリストを見る」から保存した場所を確認する
9. 保存した場所をクリックすると、観光地の詳細情報を再表示できる
10. 「行きたいリストに戻る」「ダーツに戻る」で画面を切り替えられる

## 4. 実装した機能

### 基本機能

- JavaScriptによるランダム抽選
- ダーツが飛ぶCSSアニメーション
- 気分による探検先の絞り込み
- 子ども連れ・ペット連れの条件選択
- 探検先の名称・写真・ミッション表示
- 同行条件の確認情報表示
- Googleマップへのリンク
- 条件選択画面と結果画面の切り替え
- 再抽選機能

### 今回追加したlocalStorage機能

- 「ここに行く！」ボタンで観光地を保存
- localStorageを使った行きたいリストの保存
- ブラウザを閉じても保存データが残る仕組み
- 同じ観光地の重複登録防止
- 保存した観光地の一覧表示
- 保存リストから観光地の詳細情報を再表示
- ダーツと保存リストで共通の詳細表示関数を使用
- 行きたいリストとダーツ画面の切り替え
- 詳細画面から行きたいリストに戻る機能

※同行条件には未確認の情報も含まれるため、実際の訪問前には施設の公式情報を確認してください。

## 7. 工夫した点

### ① 遊びながら行き先を決められる

単なる観光地検索ではなく、ダーツを投げるワクワク感を取り入れました。

### ② 気分や同行者に合わせた抽選

完全ランダムだけでなく、その日の気分や同行条件に応じて探検先を絞り込めるようにしました。

### ③ 結果発表を楽しめる画面構成

条件選択画面を隠してから結果を表示することで、探検先が発表される瞬間を演出しました。

### ④ 行動につながる仕組み

探検先を表示するだけでなく、ミッションやGoogleマップへのリンクを設けました。

### ⑤ 行きたい場所を保存できる仕組み

localStorageを使い、ダーツで見つけた観光地を「行きたいリスト」に保存できるようにしました。

保存した情報は、ブラウザを閉じても残るため、次にアプリを開いたときにも確認できます。

### ⑥ 詳細表示の共通化

ダーツで観光地が当たったときと、行きたいリストから観光地を選んだときに、同じ詳細画面を表示できるようにしました。

`showPlaceDetail()` という関数を作り、観光地の詳細表示処理を共通化しました。

これにより、同じ表示処理を何度も書く必要がなくなりました。

### ⑦ 重複登録の防止と画面切り替え

同じ観光地を何度も保存しないようにし、行きたいリスト・詳細画面・ダーツ画面を行き来できるようにしました。
