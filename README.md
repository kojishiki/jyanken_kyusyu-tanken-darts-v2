# 九州たんけんダーツ

## ① 制作アプリのタイトル
九州たんけんダーツ

## ② 制作アプリの説明
「次の休み、どこに行こう？」をゲーム感覚で解決する、九州のお出かけ先発見アプリです。

ボタンを押すと、おすすめスポットがランダムで選ばれ、観光地の写真やミッションが表示されます。Googleマップから目的地も確認できます。

## ③ 工夫した点・こだわった点
- 九州の地図を使い、旅行や探検をイメージできるデザインにしました。
- JavaScriptのランダム処理を使い、行き先・写真・ミッションを連動させました。
- 家族で楽しめるゲーム感覚のアプリを目指しました。

## ④ 次回トライしたいこと
- ダーツが地図に飛んで刺さるアニメーションの追加。
- 九州各県の観光スポットを増やす。
- 子ども連れ・ペット連れなどの条件検索機能。

## ⑤ 備考・感想
JavaScriptを使った自由制作で、アイデアを動くアプリにする面白さを感じました。まだ理解できていない部分もありますが、AIを活用しながら試行錯誤できたことが大きな学びでした。
