# 🎯 九州たんけんダーツ Ver.2

## 1. アプリ概要

「今日はどこに行こう？」

そんなときに、ダーツで運命の探検先を決めるWebアプリです。

九州の自然・観光地・歴史スポットなどを舞台に、行き先をランダムに決定します。

気分や同行者に合わせて候補を絞り込むこともできます。

**テーマ：まだ知らない九州に出会おう。**

## 2. 公開URL

🎯 [九州たんけんダーツ Ver.2を遊ぶ](https://kojishiki.github.io/jyanken_kyusyu-tanken-darts-v2/)

## 3. 遊び方

1. 今日の気分を選ぶ
2. 子ども連れ・ペット連れなどの条件を選ぶ
3. 「ダーツを投げる！」ボタンを押す
4. ダーツのアニメーション後、運命の探検先が発表される
5. 写真・ミッション・同行条件を確認する
6. Googleマップで場所を確認する
7. もう一度探したい場合は、条件選択画面に戻って再挑戦する

## 4. 実装した機能

- JavaScriptによるランダム抽選
- ダーツが飛ぶCSSアニメーション
- 気分による探検先の絞り込み
- 子ども連れ・ペット連れの条件選択
- 探検先の名称・写真・ミッション表示
- 同行条件の確認情報表示
- Googleマップへのリンク
- 条件選択画面と結果画面の切り替え
- 再抽選機能

※同行条件には未確認の情報も含まれるため、実際の訪問前には施設の公式情報を確認してください。

## 7. 工夫した点

### ① 遊びながら行き先を決められる

単なる観光地検索ではなく、ダーツを投げるワクワク感を取り入れました。

### ② 気分や同行者に合わせた抽選

完全ランダムだけでなく、その日の気分や同行条件に応じて探検先を絞り込めるようにしました。

### ③ 結果発表を楽しめる画面構成

条件選択画面を隠してから結果を表示することで、探検先が発表される瞬間を演出しました。

### ④ 行動につながる仕組み

探検先を表示するだけでなく、ミッションやGoogleマップへのリンクを設けました。
